# Security and Private Data

This research preview is not a secure multi-tenant service and has not undergone
a production security assessment. It does not provide authenticated reviewer
identity, enterprise RBAC, legal privilege, anonymisation or operational approval.
Configured adapters are trusted executables running with caller privileges and
environment. Separate adapter names do not prove independent models or judgment.

Keep corporate records, inputs, outputs, credentials, logs and backups outside the
repository and any synchronised public directory. `.gitignore` does not remove
already tracked content or protect Git history, forced additions or attachments.
Do not submit real meetings, customer records or privileged documents to issues,
pull requests, discussions or public AI services as part of troubleshooting.

For a vulnerability, use GitHub's private vulnerability reporting option when it
is enabled. Otherwise request a private contact channel with a minimal, non-sensitive
message. Do not post an exploit containing real credentials or confidential data.
There is no promised response SLA or paid support arrangement in this preview.

Source text is untrusted input. Exact quotes, hashes and deterministic validators
cannot guarantee semantic correctness or defeat all prompt injection. Check
proposed dependencies and adapters before execution; do not weaken evidence gates
to obtain a passing answer. A source or model error must not trigger autonomous
customer, market, regulatory or financial action.
