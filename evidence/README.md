# Source References Only

This directory contains reference metadata, not source attachments. The current
public tree includes no official PDFs, screenshots, page images or extracted full
text. The source-specific metadata in `manifest.json` is for discovery; it does
not grant permission to download, reproduce or use those sources.

For private evidence acquisition, follow
[the acquisition skill](../skills/au-lawful-source-acquisition/SKILL.md) and
[its permission contract](../SOURCE-ACQUISITION.md). Source URLs and historical
hashes help identify a version; they do not establish availability, accuracy,
copyright permission or current-law authority.

The first preview included two AEMO PDFs and two selected page renders. They have
been removed from the current tree under the references-only distribution policy.
See [Distribution](../DISTRIBUTION.md) for the separate history boundary. This
removal is not a finding that the earlier publisher-permission review was invalid.

The June 2024 NEM battery fact sheet and FY26 fees fact sheet retain their original
dates in the reference register. Neither is automatically a current rule or FY27
fee source. Check the operative instrument, publication version and later treatment.
Historical hashes are not a claim that those exact bytes can still be retrieved.

Keep all acquisition files, permission correspondence and corporate inputs outside
the public checkout. No source attachment can be admitted merely by adding a hash
or an entry to this manifest. The release scanner rejects such additions.
