# Market Data -- Residential (<100 kW)

## Feed-in Tariffs by State (2025-26)

### Overview

Feed-in tariffs (FiTs) have declined significantly from the early premium rates. Most states no longer have mandatory minimum FiTs; rates are set competitively by retailers. Typical range: 3-10 c/kWh for flat-rate FiTs.

### State-by-State FiT Summary

#### New South Wales

| Parameter | Value |
|-----------|-------|
| Regulated FiT | No mandatory minimum |
| IPART benchmark (2025-26) | 4.8-7.3 c/kWh (all-day) |
| Retailer offers | 3-8 c/kWh (competitive market) |
| Time-varying offers | Some retailers offer higher evening FiT (up to 12 c/kWh) |
| Legacy premium FiTs | 20 c/kWh gross (closed to new applicants since 2011) |

#### Victoria

| Parameter | Value |
|-----------|-------|
| Regulated minimum FiT | **Removed from 1 July 2025** (previously set by ESC) |
| Previous minimum (2024-25) | Time-varying: 2.1 c/kWh (daytime) to 6.6 c/kWh (peak) |
| Retailer offers (2025-26) | 3-8 c/kWh (flat); some time-varying offers |
| Solar Homes Program | State battery rebate available (up to $2,950) |

#### Queensland

| Parameter | Value |
|-----------|-------|
| Regulated FiT | No mandatory minimum |
| Typical retailer FiT | 5-8 c/kWh |
| Regional FiT (Ergon) | 6-8 c/kWh (uniform tariff area) |
| Legacy premium FiTs | 44 c/kWh (closed 2012; ongoing for existing recipients until contract end) |

#### South Australia

| Parameter | Value |
|-----------|-------|
| Regulated FiT | No mandatory minimum |
| Typical retailer FiT | 3-7 c/kWh |
| SA has highest solar penetration | Daytime export value very low; midday FiT approaching zero |
| Time-varying | Evening exports valued higher than midday |

#### Tasmania

| Parameter | Value |
|-----------|-------|
| Regulated FiT | No mandatory minimum |
| Typical retailer FiT | 5-8 c/kWh |
| Aurora Energy (incumbent) | ~6-7 c/kWh |

#### Western Australia

| Parameter | Value |
|-----------|-------|
| Distributed Energy Buyback Scheme (DEBS) | Synergy: 2.25 c/kWh (daytime 3pm-9pm: 10 c/kWh) |
| Midday buyback | Very low (2.25 c/kWh) reflecting oversupply |
| Emergency Solar Management | WA can remotely curtail solar during system security events |

### Key Trend

The biggest shift is timing. Midday exports are worth very little due to solar saturation, while evening exports (when solar generation drops but demand peaks) command a premium. This is driving battery adoption and time-of-use FiT structures.

## Solar + Battery Payback Analysis

### Solar-Only System (6.6 kW)

| Parameter | Value |
|-----------|-------|
| System cost (installed, after STC rebate) | $4,000-$7,000 |
| STC rebate value | ~$2,500-3,500 (zone-dependent) |
| Annual generation | 8,500-10,500 kWh |
| Self-consumption rate (no battery) | 25-40% |
| Annual savings | $1,000-$1,800 |
| Simple payback | 3-5 years |

### Solar + Battery System (6.6 kW + 10 kWh)

| Parameter | Value |
|-----------|-------|
| System cost (installed, after rebates) | $12,000-$18,000 |
| Battery rebate (VIC Solar Homes) | Up to $2,950 |
| Self-consumption rate (with battery) | 60-80% |
| Annual savings (electricity + FiT optimisation) | $1,800-$2,800 |
| Additional VPP revenue | $200-$600/year |
| Simple payback (battery component) | 7-12 years |
| Simple payback (total system) | 5-8 years |

### Payback Sensitivity

| Factor | Increases Payback | Decreases Payback |
|--------|------------------|------------------|
| Retail electricity rate | Lower rates | Higher rates (SA best case) |
| Self-consumption rate | Low (export-heavy) | High (daytime load) |
| FiT rate | Low FiT (less export value) | High FiT or TOU premium |
| System cost | Higher install cost | Lower cost (competition) |
| Battery cycling | Low utilisation | High utilisation + VPP |

## VPP Programs

### Active VPP Programs for Residential

| Program | Provider | Battery Required | Typical Revenue |
|---------|----------|-----------------|----------------|
| Tesla Energy Plan | Tesla / Retailers | Tesla Powerwall | Free electricity + VPP participation |
| AGL Virtual Power Plant | AGL | Various compatible | $200-600/year credits |
| Origin Loop VPP | Origin Energy | Various compatible | $200-500/year credits |
| Reposit VPP | Reposit Power | Reposit-compatible | Grid credits for peak dispatch |
| sonnen VPP | sonnenBatterie | sonnen battery | FiT premium + VPP credits |
| SA VPP (Government) | SA Gov / Tesla | Tesla Powerwall | Subsidised battery + VPP enrolment |
| Community Batteries | Various DNSPs | N/A (shared battery) | Improved FiT for participating households |

### VPP Revenue Model

```
Revenue Sources:
1. Wholesale arbitrage     [Charge off-peak; discharge at peak prices]
2. FCAS participation      [Fast frequency response via aggregated batteries]
3. Network support         [Peak demand reduction on constrained feeders]
4. Retailer incentive      [FiT premium or bill credit for VPP enrolment]

Typical total VPP value: $200-$600/year per household battery
```

| Parameter | Value |
|-----------|-------|

| STCs per kW (Zone 3, 2026) | ~13 STCs per kW of PV installed |
| STC value for 6.6 kW system (Zone 3) | ~$3,200-3,400 |
| STC assignment | Usually assigned to installer who provides point-of-sale discount |
