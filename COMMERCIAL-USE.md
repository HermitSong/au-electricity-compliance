# Commercial Use

Policy summary, not a substitute for the [licence](LICENSE).

| Scenario | Project licence permission |
| --- | --- |
| A student studies the source; a researcher tests retrieval | Free |
| A retailer runs an internal compliance assistant in production | Free |
| A storage operator modifies the workflow for its own operations | Free; no duty to publish internal changes |
| A contractor charges to maintain a private client-controlled instance | Allowed within section 3; no reusable external product grant |
| A business pays ordinary cloud hosting or model API charges | Allowed for permitted use |
| A retailer sends an ordinary explanation to a customer or regulator | Allowed; source, privacy and professional obligations still apply |
| A contributor publishes an unpaid source fork under the same terms | Allowed; retain notices and identify changes |
| A company sells a copy, paid knowledge package or white-label version | Separate written commercial licence required |
| A provider exposes project functionality through paid SaaS, API or chatbot | Separate written commercial licence required |
| A provider sells managed compliance answers substantially based on the project | Separate written commercial licence required |
| A developer independently obtains official laws and creates its own system | Not prohibited by this licence |

## Enquiries

Contact [HermitSong](https://github.com/HermitSong) through a minimal non-sensitive
[repository issue](https://github.com/HermitSong/au-electricity-compliance/issues)
to request a private commercial-licensing contact channel. Do not post customer
records, legal advice, business plans, private source code or credentials.

There is no published price, automatic commercial permission, regulatory approval
or guaranteed support. A commercial licence must identify the rights holder,
covered material/version, permitted offering and agreed terms in writing. It
cannot override third-party rights.

## Boundaries

Free enterprise Internal Use does not mean free operation: hosting, model usage,
maintenance and professional review may cost money. Licence permission is not
permission to take a regulated action. No accuracy, compliance or endorsement is
guaranteed. This custom source-available licence has no BSL-style conversion date
and has not received independent legal review.
